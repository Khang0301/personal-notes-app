# Personal Notes App

A full-stack personal notes management application built as a personal portfolio project.

## Project Goal

The application allows users to create, manage, search, organize, and secure their personal notes.

## Planned Features

- User registration and login
- JWT authentication
- Create, edit, and delete notes
- Search, filter, and sort notes
- Categories and tags
- Favorite and pinned notes
- Archive and trash
- User profile and settings
- Light / dark mode

## Tech Stack

### Frontend

- React
- JavaScript
- Vite

- Axios

### Backend
